# Live Text for Video

[English](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | **한국어** | [Français](README.fr.md) | [Deutsch](README.de.md) | [Español](README.es.md) | [Русский](README.ru.md)

**동영상을 일시정지하고 오른쪽 아래 아이콘을 클릭하면, 화면 속 텍스트를 바로 드래그해서 선택할 수 있습니다.**

인식 엔진은 Apple의 **Vision 프레임워크** — Safari의 「라이브 텍스트」와 **완전히 동일한 엔진**이라 품질도 같습니다.

보너스: 인식 결과가 **실제 DOM 텍스트**로 배치되므로, Yomitan 같은 사전 확장 기능에서 **그대로 마우스를 올려 단어를 찾을** 수 있습니다. 복사할 필요가 없습니다.

> 이 문서는 요약본입니다. 전체 내용은 [영문 README](README.md)를 참고하세요.

![demo](docs/demo.png)

> 동영상을 일시정지하고 오른쪽 아래 아이콘을 클릭하면 화면 속 텍스트가 선택 가능해집니다. 파란 배경은 인식된 위치입니다.

## 무엇을 해결하나요

Safari에서는 동영상을 일시정지하면 「라이브 텍스트」 버튼이 나타나고, 화면 속 텍스트를 바로 선택·복사할 수 있습니다.

하지만 Chrome에는 이 기능이 없습니다 — **웹 페이지 샌드박스에서는 시스템 OCR에 접근할 수 없기** 때문입니다. 순수 프런트엔드 방식은 범용 OCR 모델을 브라우저에 넣어야 하고, 품질과 속도가 모두 떨어집니다.

이 프로젝트는 **Chrome 확장 프로그램 + 작은 로컬 헬퍼**로 그 경험을 Chrome에 옮깁니다. 확장 프로그램이 UI와 프레임 캡처를, 헬퍼가 Apple Vision 엔진 호출을 담당합니다.

## 요구 사항

| 항목 | 요구 사항 |
|---|---|
| 운영체제 | **macOS 13 이상** (그 이하 버전에는 자동 언어 감지 기능이 없습니다) |
| CPU | Apple Silicon 또는 Intel (백엔드는 Universal Binary) |
| 브라우저 | Chrome / Edge / Brave / Vivaldi / Opera (Chromium 계열) |
| 백엔드 빌드 시 | Command Line Tools: `xcode-select --install` |

> **Windows / Linux에서는 동작하지 않습니다** — 엔진이 macOS 전용입니다.
> **Safari는 지원하지 않습니다** — 확장 API가 Chrome 계열과 호환되지 않습니다.

## 설치

### 1단계: 클론 및 등록

```bash
git clone https://github.com/ChenZhuo4649/live-text-for-video.git
cd live-text-for-video
./install.sh
```

스크립트가 하는 일:

1. 운영체제 버전과 CPU 아키텍처 확인
2. OCR 백엔드 준비 — 사용 가능한 것이 있으면 건너뛰고, 없으면 `swiftc`로 **Universal Binary** 빌드
3. 이 Mac의 **모든 Chromium 계열 브라우저**에 백엔드 등록
4. 확장 프로그램 설치 절차 출력

### 2단계: 확장 프로그램 설치

1. `chrome://extensions` 열기
2. 오른쪽 위 **「개발자 모드」** 켜기
3. **「압축해제된 확장 프로그램을 로드합니다」** 클릭 후 저장소의 `extension/` 폴더 선택

확장 프로그램 ID는 다음과 같이 표시되어야 합니다:

```
hmigekegioajglfmifdfofilgigpbcah
```

> **이 ID는 확장 프로그램에 내장된 공개 키에서 계산되며 설치 경로와 무관합니다.**
> 다른 컴퓨터, 다른 폴더, 다른 브라우저에서도 동일합니다.

## 사용법

1. 아무 동영상 페이지나 열기 (YouTube, 네이버 TV 등)
2. **일시정지**
3. 동영상 **오른쪽 아래에 작은 원형 아이콘**이 나타남
4. **클릭**
5. 약 0.5~1초 후 화면 속 텍스트가 선택 가능해지고, **연한 파란 배경이 잠깐 번쩍여** 텍스트 위치를 알려줍니다
6. **드래그해서 선택 → `Cmd+C`**
7. **아이콘을 다시 클릭**하면 해제됩니다

---

### 선택 사항: 일시정지 시 자동 인식

![extension panel](docs/popup.png)

확장 아이콘을 클릭해 **「일시정지 시 자동 인식」** 을 체크하면,
일시정지만 해도 텍스트가 나타납니다. 아이콘을 클릭할 필요가 없습니다.

대신 일시정지할 때마다 인식(약 0.5~1초)이 실행되므로 **기본값은 꺼짐**입니다.

## 인식 품질 (실측)

| 콘텐츠 유형 | 결과 |
|---|---|
| URL, 코드, 큰 고대비 텍스트 | ✅ 완벽 |
| 중국어 / 일본어 자막 | ✅ 완벽 |
| 빽빽한 터미널 텍스트 | ✅ 128줄 중 72% 완벽 |
| 저대비 회색 텍스트 | ❌ 실패 — 다만 신뢰도가 0.3으로 떨어져 판별 가능 |

처리 시간: 일반 화면 **0.5~1초**, 빽빽한 터미널 화면 약 **1.1초**.

## 언어 설정

**기본값은 자동 감지**입니다 (Vision의 `automaticallyDetectsLanguage`). 중국어·영어·일본어를 그대로 처리합니다.

> **`ja-JP`와 `zh-Hans`를 동시에 넘기면 안 되는 이유**: Vision의 언어 팩은 **상호 배타적**입니다.
> 둘 다 넘기면 중국어가 번체자나 일본어 한자 이체자로 변형되고(师→姉, 试→試, 给→給, 这→汶),
> 처리 시간도 거의 두 배가 됩니다.
> 동일한 일본어 시험 화면 실측: `zh-Hans`만 → **11줄**, `auto` → **44줄**.

화면이 단일 언어임을 아는 경우에는 수동 지정이 **더 빠릅니다**. 확장 아이콘 클릭 → 「中文 + 英文」 또는 「日文 + 英文」 선택.

## 일본어 사전 확장과 함께 쓰기 (Yomitan 등)

텍스트 레이어는 **의도적으로 일반 DOM에 배치**했습니다 (Shadow DOM에 숨기지 않음). 따라서 Yomitan 같은 사전 확장이 스캔할 수 있고, **Shift를 누른 채 마우스를 올리면 바로 단어를 찾을** 수 있습니다.

이를 위해 세 가지를 조정했습니다:

| 조정 | 이유 |
|---|---|
| `color: #fff` + `-webkit-text-fill-color: transparent` | 사전 확장이 `color`로 "보이는 본문인지" 판단하는 경우가 있어, `transparent`를 직접 지정하면 건너뛸 수 있습니다 |
| **2단계 너비 보정** (폰트 크기 자동 조정 + letter-spacing) | 사전은 「마우스 좌표 → 문자 인덱스」로 검색합니다. 렌더링 너비가 실제와 다르면 문자 인덱스가 **누적해서 어긋납니다** |
| CJK 텍스트의 **반각 공백을 전각으로 변환** | OCR이 반각 공백(전각의 약 1/4)을 반환해, 이후 문자들이 앞으로 밀립니다 |

> ⚠️ 이 보정에 `transform: scaleX`를 쓰지 마세요 — 마우스 히트 테스트를 방해해 드래그 선택과 호버 위치가 모두 깨집니다.

## 알려진 제한

| 제한 | 설명 |
|---|---|
| 플레이어 UI도 인식됨 | **합성된 화면 픽셀**을 캡처하므로 진행 표시줄·버튼 문자도 함께 찍힙니다. Safari에는 없는 문제입니다 |
| DRM 콘텐츠 불가 | Netflix 등은 검은 화면이 나옵니다 |
| 드물게 1글자 어긋남 | 한자 / 가나 / 숫자 / 기호의 폭이 본래 다르기 때문입니다 |
| 개발자 모드 알림 | Chrome 시작 시 「개발자 모드 확장 프로그램을 사용 중지하세요」 알림이 뜹니다. 동작에는 영향이 없습니다 |


## 제거

1. `chrome://extensions` → **Live Text for Video** → **삭제**
2. 등록 파일 삭제 (브라우저 폴더명은 환경에 맞게 변경):

```bash
rm "$HOME/Library/Application Support/Google/Chrome/NativeMessagingHosts/com.livetext.videoocr.json"
```

3. 저장소 폴더 삭제
